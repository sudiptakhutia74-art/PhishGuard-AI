# 🛡️ PhishGuard AI: Next-Gen Email Security

![Python](https://img.shields.io/badge/Python-3.9+-blue.svg)
![FastAPI](https://img.shields.io/badge/FastAPI-Modern%20Framework-green.svg)

PhishGuard AI is an advanced cybersecurity solution designed to detect and neutralize phishing threats in real-time. By leveraging a custom-tuned **BERT (Bidirectional Encoder Representations from Transformers)** model, it analyzes the semantic intent of emails to identify malicious patterns that traditional filters miss.

## ✨ Key Features
* **Sentinel AI Chatbot:** Real-time analysis of suspicious links and text.
* **Deep Intent Analysis:** Uses NLP to detect social engineering tactics.
* **Modern Dashboard:** Built with FastAPI and a dark-themed, responsive UI.
* **Secure Deployment:** Containerized with Docker for high availability.

## 🛠️ Tech Stack
* **Backend:** FastAPI (Python)
* **AI Model:** DistilBERT-base-uncased
* **Frontend:** HTML5, CSS3, JavaScript
* **Cloud:** Hugging Face Spaces & Docker
